# Diagnosing SDLC

Before retrying a failed session, diagnose with citations (`path:line` for
code, quotes for conversation).

1. **What happened**: intended workflow vs actual sequence.
2. **First deviation**: the earliest step where behavior diverged (missed skill? skipped gate? wrong assumption?).
3. **Cause class**: trigger miss (description too weak), instruction miss (skill unclear), or judgment miss (right skill, wrong call).
4. **Fix**: smallest change — tighten a description, add a Red-Flag row, or adjust the plan. Verify via `writing-skills` step 2.
